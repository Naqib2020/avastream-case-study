# AvaStream / Auktion Live

Public-safe case study for a private commercial platform.

## Overview

AvaStream is a live-commerce auction platform focused on seller workflows, scanning, showcase synchronization, realtime auction activity, authenticated dashboards, payments, shipping/tracking, and admin operations.

## My Role

Designed and developed major frontend and backend workflows for the platform, including dashboard routes, live auction surfaces, admin areas, API-backed flows, and realtime auction behavior.

## Platform Modules

- Public platform pages
- Buyer dashboard and seller dashboard workflows
- Live auction and mobile live-auction interfaces
- Marketplace/showcase synchronization
- External scan APIs and settings
- Orders, payments, shipment tracking, and invoices
- Admin dashboard, users, marketplace sync, content, health, and settings
- Realtime auction events and bid/comment submission flows

## Technology

- Laravel 12, PHP 8.2, Sanctum
- React, TypeScript, Vite, React Router
- Tailwind CSS and Radix/shadcn-style component patterns
- Echo/Pusher-style realtime events
- Stripe, Firebase Messaging, shipping/tracking integrations

## Technical Highlights

- Built route structures for admin, buyer, seller, verification, marketplace, and live auction areas.
- Connected internal scan/listener APIs to auction workflows.
- Integrated realtime auction state updates into frontend experiences.
- Supported payment and shipment flows around auction orders.
- Added admin tools for marketplace sync, users, content, verification, and platform health.

## Privacy

The source code is private. This case study excludes credentials, tokens, private seller/buyer data, internal endpoints, streaming configuration, marketplace account data, orders, payment records, and admin screenshots.
